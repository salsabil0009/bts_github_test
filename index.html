Présentation - GIT

Qu'est-ce que Git ?

Git, créé en 2005 par Linus Torvalds, est aujourd’hui l’outil de versionning le plus utilisé dans le
développement logiciel. Il permet de conserver un historique complet des changements, de
travailler à plusieurs sans écraser le travail des autres, et de créer des branches pour développer
des fonctionnalités en parallèle. Grâce à son fonctionnement décentralisé, chaque développeur
possède une copie complète du projet, ce qui rend Git à la fois rapide, flexible et très fiable.

Quelques fonctionalités Git

Git offre plusieurs fonctionnalités clés qui facilitent le travail des développeurs. Il permet
d’enregistrer l’historique complet d’un projet grâce aux commits, de créer des branches pour
développer des fonctionnalités sans toucher au code principal, puis de fusionner ces branches
avec un merge. Git facilite aussi la collaboration : chacun peut travailler en parallèle sans écraser
le travail des autres. Enfin, il permet de revenir à une version précédente du projet, de comparer
des modifications, et de gérer des contributions via des dépôts distants comme GitHub.

Présentation - GitHub

Qu'est-ce que GitHub ?

GitHub fonctionne comme un espace centralisé où les développeurs peuvent créer des dépôts
(repositories) pour héberger leurs projets, suivre les modifications au fil du temps, collaborer
facilement en équipe et proposer des améliorations via des outils comme les pull requests. Il offre
aussi des fonctionnalités supplémentaires comme la révision de code, la gestion de projet et
l’hébergement de millions de projets open source. En résumé, GitHub est l’endroit où les
développeurs travaillent ensemble, partagent leurs idées et construisent des logiciels de manière
organisée et transparente.
